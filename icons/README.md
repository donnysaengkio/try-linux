# Icons

The icons all three editions draw, so Windows, macOS and Linux look the same. They are
[Lucide](https://lucide.dev) icons (lucide-static 0.460.0), unchanged, under the ISC license in
[LICENSE](LICENSE).

| Icon | Used for |
| --- | --- |
| `wrench`, `monitor`, `usb`, `undo-2` | Settings tabs: General, Hardware, Devices, Recovery |
| `settings` | A system's Settings button |
| `terminal` | A system's console button |
| `menu` | The main menu |
| `x` | Close |
| `arrow-left` | Back |
| `pencil` | Rename a system |
| `chevron-down`, `chevron-right` | Drop-downs, menu buttons and settings sections |

To add one, copy its SVG from lucide-static's `icons/` folder here. The Windows edition embeds
every SVG in this folder when it is built.
